# Security Policy

## Supported Versions

`fastapi-code-generator` is no longer maintained. No version receives security fixes.

See [Maintenance Status and Migration](README.md#maintenance-status-and-migration) for details.

## Reporting a Vulnerability

Vulnerability reports for this project are no longer triaged or fixed, including reports about its dependencies.

## Guidance for Existing Users

- Migrate to [datamodel-code-generator](https://datamodel-code-generator.koxudaxi.dev/), following the [migration guide from fastapi-code-generator](https://datamodel-code-generator.koxudaxi.dev/fastapi-code-generator-migration/).
- Do not run `fastapi-code-generator` on untrusted or attacker-influenced OpenAPI documents.
- Review generated code before importing or running it.
